# 天一 Skills

这里收录天一在写作、品牌内容生产和 Agent 协作中形成的工作方法。每个 Skill 都有一个明确的使用场景，你可以把它交给 Agent，拿自己的素材和问题试一次。

## 从一个问题开始

| 你手上有什么 | 用哪个 Skill | 会得到什么 |
| --- | --- | --- |
| 一个沿用很久、越来越难以解释现实的工作方式 | [革命者视角](skills/tianyi-revolutionary/SKILL.md) | 要改变的规则、可检验的替代方案和复做条件 |
| 一堆笔记，或者一篇越改越不像自己的稿子 | [写作与文风对齐](skills/voice-anchor/SKILL.md) | 带素材出处的骨架，或经过样本对照的草稿 |
| 几个电商品类，还不知道该先测哪个 | [流量先行选品](skills/tianyi-commerce/SKILL.md) | 候选品判断、内容实验和进入打样的条件 |
| 一套已经做过几次的品牌素材交付 | [品牌内容系统](skills/tianyi-brand-content/SKILL.md) | 品牌锚点、场景卡和按套验收的清单 |
| 一条需要多个 Agent 接力的业务流程 | [超级组织](skills/tianyi-super-organization/SKILL.md) | 一份可交接的任务约定，以及权限、记忆与验收设计 |
| 做过一次真实交付、实验或失败，想让别人能从中学到东西 | [公开工作记录](skills/tianyi-build-in-public/SKILL.md) | 有事实出处的 Build in Public 草稿 |
| 笔记不少，结论却散在各处 | [知识库复利](skills/tianyi-knowledge-compounding/SKILL.md) | 可查证、可持续更新的主题页 |
| 想让 Agent 稳定复跑一项任务 | [可重启的 Agent 循环](skills/tianyi-agent-loop/SKILL.md) | 带证据、预算、停止条件和交接的循环约定 |

更多来源和待沉淀的主题见 [方法地图](docs/skill-map.md)。

想把这套思路当作线上分身使用，从「革命者视角」开始，给 Agent 一个你正面对的具体问题。它会用这里公开的观点追问和推演，并说明哪些是根据当前问题得出的判断。

## 怎么用

下载需要的 Skill 文件夹。支持 Agent Skills 的客户端可以按各自的安装方式添加整个文件夹。也可以直接将 `SKILL.md` 和它链接的参考文件交给 Agent，再附上任务材料。库内方法以 Markdown 提供，无需连接私人知识库。

例如：「用 tianyi-commerce 帮我判断，桌面摆件和手机挂绳哪个更适合先做一轮内容测试。我的时间是两周，预算是 1000 元。」

## 方法从哪来

「革命者」是天一对自己的要求。它从三个地方落到实处：在一线看清旧做法的代价，在自己的工作里试出替代办法，再交给别人复做。BrandOS 的内容交付设计、木林 Agent 的协作实践和写作复盘，分别提供了不同的观察场景。每个 Skill 只做它能交付的那部分工作，试验中的判断会标明验证条件。

受 [Don't Be Silent 的 dbskill](https://github.com/dontbesilent2025/dbskill) 的工具箱形式启发。Skill 的方法来自天一的笔记和项目实践。
