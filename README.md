# 天一 Skills

## voice-anchor · 文风对齐写作

用作者的真实原文校准文风。适合把中文闪念、口述或对话整理成文章，也适合检查一篇改完后失去原有语感的稿件。

准备本次写作素材和两到三篇同文体的手写或口述原文。Agent 先读样本，交付标有素材出处的段落骨架。骨架确认后再成文，并逐段对照样本检查事实、论证和语感。

支持 Agent Skills 的客户端可添加整个 [voice-anchor 文件夹](skills/voice-anchor)。也可将 [SKILL.md](skills/voice-anchor/SKILL.md) 和 [骨架与差异对照表](skills/voice-anchor/references/review.md) 连同素材交给 Agent。
