# 流量先行选品

这是从 AI-native 电商品牌实验里整理出的待验证路线。先用内容找到受众和需求，再决定供应链投入。

1. 记录目标市场、受众、候选品、现有分发渠道、可用预算和试验窗口。优先测试审美能左右购买、传统素材制作费时、且能用同一内容管线反复呈现的品类。
2. 核实供应商能否寄样、小单或代发。把尺码退货、售后复杂度、资质、运输和预期利润记入每个候选品的门槛。缺关键数据时标为待查。
3. 围绕同一受众测试少量可比较的内容。尽量一次只变一个主要变量，例如商品、场景或卖点。内容上线前定好分母、最低样本、时间窗和继续条件。概念渲染标明是概念，实际供货和效果由样品验证。
4. 分开读三类证据。内容信号看停留、收藏或相对点击，需求信号看有效询价、留资，商业信号看真实成交、退款与扣除交付成本后的毛利。流量样本不足时，保留不确定性，优先修正触达或试验设计。
5. 用现成品或小单验证实物与履约，再决定来图定制、批量和质检。样品和小单分别记录报价、时效、质量及退货原因。

交付候选品对照、首轮内容实验、继续或停止门槛，以及下一笔投入要买到的证据。

## 实验记录

在发布第一条内容前填写这张表，跑完后保留原先的门槛。

| 阶段 | 记录什么 | 下一步的判定 |
| --- | --- | --- |
| 受众 | 账号主题、目标人群、触达渠道、可持续发布的频率 | 同一人群可重复触达，能够安排一轮可比试验 |
| 内容 | 商品、素材变量、曝光与有效观看数、发出时间 | 相对表现可复查，获得足够样本进入需求测试 |
| 需求 | 曝光或落地页访客作为分母、去重询价和留资、意向集中在哪个款式或价位 | 需求证据达到事前门槛，才申请样品或测现成品 |
| 商业 | 真订单、到账、退款、运费、获客与返工 | 履约可接受且扣除实际成本后仍能支撑下一笔投入 |

### 矛盾信号怎么判

- 曝光高、询价少：先看受众是否只是喜欢内容，再检查卖点、报价或购买入口。下一轮只改其中一个变量。
- 曝光低、少量询价质量高：优先加一个可比渠道补触达，记录各渠道分母，避免拿绝对询价数比较。
- 询价强、样品不稳：保留需求结论，供应链仍停在样品阶段。比对多家同规格样品，分别记拿样、批量和定制报价。
- 成交有、退款或售后吞掉利润：把问题落到商品、履约或预期管理，先修导致损失的一环。

### 选品记录示例

桌面摆件和手机挂绳是虚构候选。用同一个生活方式账号分别做一条日常使用场景和一条特写，轮换发布时间。两款都用相同的意向收集入口，单列款式及价格区间，避免把评论数当订单。用相同口径记有效询价。只对过门槛的一款查样品、交期与实际到手成本，未达门槛则记录需要改变的一个变量。
