# voice-anchor：文风对齐写作

## 原则

本 skill 的核心机制是写前对齐，不是写后检测：文风由样本锚定产生，不由规则
清单产生；规则只负责约束组织方式与红线。任何"风格画像""风格摘要"类文件
只做索引导航，禁止替代样本原文进入写作上下文。

## 硬红线（违反任意一条，成文作废）

**R1 事实零发明，表述零抹平。** 动笔前先整体盘点一遍全部素材；成文中的
每一个具体细节（场景、物件、数字、对话、心理活动、引文）都必须能指回素材
中的原文，素材里没有的细节一律不写。同时禁止隐形改写：素材中的模糊量词不
得坐实，口语化表述不得书面化，征询语气与自我修正按素材保留，带人味的冗余
不因追求效率删除。

**R2 思想浓度优先时，平铺直叙。** 当文章重心是思考本身，叙述部分只负责交
代事实背景，用干练的白描寥寥数笔完成；禁止为营造文学感而添加氛围描写（环
境渲染、感官铺陈、悬念铺垫）。散文与记录类文体默认本条生效。

**R3 立意藏进描写。** 直接点题、总结、评论的句子，凡能被一个事实、场景或
引文替代的，一律替代；文章的主张由材料的取舍呈现，不由宣告呈现。散文与记
录体的篇幅重心放在描述本身（客观事实、引文、场景），立意通过"选什么来描
述"传达；节奏张弛有度：背景与过程平铺直叙快过，核心概念处放缓展开。开篇
的对照与反差只能使用素材中有出处的观察，禁止虚构"常规认知""正常人观点"
作为被推翻的靶子。

**R4 具体先于抽象。** 段与篇的默认顺序：先现象与客观事实，用干练的文笔寥
寥数笔交代背景；再展开分析、提供数据；最后才落到概念与观点，观点必须长在
事实之上。检验法：删掉结尾的升华部分，正文应仍然完整自洽。

**R5 以人的思维为导向，组织方式随内容性质切换。** 感受性与论述性段落按递
进关系组织：写完这句才想下一句，顺着上一句的意思跟进；禁止预声明清单（先
报数量再逐条）、禁止为表达效果发明包装性框架（给观点命名、设比喻式分类）。
结构性内容（计划、功能、步骤、分工）则天然适配清单，按素材原样使用，不必
散文化，也不得加预告式的总起句。同一篇内允许两种组织方式并存，按段落功能
切换。若素材主体来自 AI 生成的对话或资料，其论证组织（总起判断句、分类枚
举、引文配菜、升华收束）默认不可信，须先按本条重排再动笔，禁止只改词句保
留原骨架。

**R6 引用自然。** 引经据典作为论述的自然部分嵌入，引完即用，不复述、不拔
高。散文中禁止工整对仗式收束句；格言式句子不得等距分布，连续两段不得都以
格言或对仗收尾。

**R7 列举不同构。** 列举与清单中，各项的句式不得完全同构；每项的长短与详
略跟随素材的信息权重，该长则长，该短则短，禁止为节奏整齐将各项削成同一模
板的排比。

**R8 概念抛出必须接住展开。** 行文中引入的每一个新概念（自造的说法、比
喻、术语），出现后必须随即展开它是什么、指什么，可用自问自答承接；禁止抛
出即收，把解释留给读者的想象。

**R9 引入即完成。** 每一处引入必须由下一句完成交代：宣布一个分类，先列全
部类目再逐项展开；引用一句诗文，出处与全句紧随其后一次给全；前文已交代过
的信息不再原样重复。禁止"宣布—跳过—展开"的断裂，禁止同段重复引用同一
句原文。

## 内容深化规则

深化的合法边界只有一条：把素材里已有的意思说透，是深化；引入素材里没有的
事实、场景、数字、引文，是发明，按 R1 禁止。深化做的是放大与理顺，不是添
料。

**D1 概念拓展。** 素材中的概念断言（自造的说法、术语、比喻）成文时按 R8
展开到位：它是什么、指什么、边界在哪。展开的依据须能指回素材，优先用素材
内其他段落互证；素材不足以支撑展开的，标注后交用户裁决，不得硬编。

**D2 逻辑理顺。** 素材论证链的缺口（跳跃、因果不显、总-分缺失）成文时补
全：显式逻辑连接、过渡句、总起与收束。理顺补的是连接组织，不新增事实断
言，不必逐处标注；但改变了素材原有论证顺序的，须在 diff 中标注。

**D3 案例补充。** 补充案例只能来自三个来源：(a) 用户提供的其他素材；(b)
用户授权访问的真实记录；(c) 经用户确认的外部事实。禁止编造案例。默认不
主动补，仅当论证缺口大到没有案例撑不住、或用户指定时补充；每个补充案例在
diff 中单独标注来源与原文位置，交用户裁决。

**深化幅度按文体分档**（默认档位，用户可单篇调整；档位标准待用户裁决定
稿）：

| 文体 | 档位 | 规则 |
|---|---|---|
| 个人记录 | 零深化 | 只整理成文，不做深化 |
| 社媒短帖 | 轻深化 | 原文为主；只做 D2，D1 仅一句话点破，不用 D3 |
| 公众号长文 | 重深化 | 原文只作骨架；D1 全面展开，D2 全面理顺，D3 按需并标注来源 |

## 文体结构库

### 散文 / 记录体
- 篇幅重心在描述（客观事实、引文、场景），立意通过素材的选择呈现，不通过宣告（R3）
- 张弛：背景与过程平铺直叙快过，核心概念处放缓展开；何处展开拿不准，在骨架阶段交用户裁决
- 问答体成链：答接问话头，下一轮承接上一轮落点（见语感基线）

### 社媒文章（PAS 三段式，起步文体）
结构简单，适合作为 skill 的第一个实战文体；叙事方式（语感、语气、连接）仍按本 skill 全部规则执行。

1. **痛点（Problem）**：先抛出读者关切的问题，用提问或场景让对方"对号入座"
2. **放大（Agitate）**：解释并放大这个痛点——后果是什么、为什么一直存在、用真实经历引发共鸣
3. **方案（Solution）**：引出解决方案，具体、分点、可带走
4. **（可选）互动引导**：社媒平台特性，结尾引导评论/收藏

变体与迁移：
- 干货清单型：痛点引入 → 数字预告（"X 个方法"）→ 清单展开 → 互动引导
- 同一结构可写成文章、图文（标题抛问题/冲突，正文承接展开，标题与正文不重复信息）、视频脚本
- 调研依据（2026-10-09）：PAS 为经典文案框架（Copyblogger / AWAI / Drip 等）；中文社媒通行三段式与互动第四步（小红书运营结构公式，艾讯客 2025-04 等）

## 流程（顺序不可跳）

**Step 0 定位问询。** 确认文体与用途：个人记录 / 公众号长文 / 社交短帖 /
对外发布。结构元素（标题方式、小标题、署名、分段密度）按定位取舍；同时按
文体确定深化档位与排版档位（见内容深化规则、排版规范），用户可单篇调整。
定位不明必须先问，默认按个人记录处理（朴素标题、无小标题、无署名、零深
化）。

**Step 1 样本锚定。** 从样本库按文体匹配优先、主题相近次之的原则，选 2-3
篇样本原文全文读入上下文；写作全程随时回看。公众号等发表场景另取 1-2 篇
成文样本校准发表形态（形态基准不校准声音）。

**Step 2 骨架先行。** 先交结构稿：每段一句话，注明该段功能（事实 / 引用 /
分析 / 观点 / 过渡）与素材出处；同时标注深化点——哪些概念按 D1 展开、哪
些论证缺口按 D2 补、何处拟按 D3 补案例及来源。骨架经确认后才展开成文。

**Step 3 对照生成。** 逐段写作，每完成一段，对照样本中的同类段落自问：这
一句用户本人会怎么说。凡说不出明确偏离理由的，改回样本的语感分布。

**Step 4 diff 验收。** 输出对照表：成文每段 vs 样本同类段，标注每处偏离及
理由，交用户裁决。深化与排版分层标注：D1/D3 深化点单独列出（含来源与素
材原文位置），排版调整单独出 diff，与内容修改分开。用户指出问题后按段修
改，不整篇重写。

末道工序：成文后可再跑通用去 AI 味检测类 skill 兜底，但其结论不覆盖本
skill 的样本对照结果。

## 语感基线

- 长句为主、逗号推进，一句把逻辑说到底，节奏有呼吸感；平铺直叙指不搞氛围
  渲染，不是把句子削短削快
- 感悟型内容禁用定理式断言语气：论断句改为体会句，舒缓与体感词（或许、可
  能、其实、就、的感受、恰恰、大概）落位，密度向样本对齐，不逐句堆砌
- 句间需要显式连接与回指（因此、那么、这里、这个、它），保持线头不断
- 问答体成链：答的开头接住问的话头（虚拟语气应答、复述条件再转折），下一
  问或下一答承接上一轮的落点
- 单句成段全文不超过 1 处，且必须用于承重位置
- 破折号全文不超过 3 处
- 口语连接词与自我修正（"其实""或者说"一类）按样本中的自然频率使用，不
  额外堆砌
- 强调靠重复，不靠变奏：同一个关键句可以在相邻位置再次出现
- 开篇平铺直叙，交代事实即止
- 问答体（如适用）：问、答各自独立成行，不设角色称呼；回答方不加戏（不自
  嘲、不抢话、不接错话、不为提问方补写心理活动）

## 排版规范（形态层）

排版只动分段与视觉元素，不动文字本身。排版调整与内容修改分开交付，禁止排
版时顺手改内容。

**段落长度（建议默认档，以真机预览校准后由用户定档）：** 公众号每段不超过
约 5 行（约 100 字）；思想浓度高的论断段可放宽至约 7 行，每篇不超过 3 处。
检验标准：手机上一屏内至少出现一个段落断点。

**拆分原则：** 在语义单元完成处断——一个意思说完整即断段，拆出的每段须能
独立成立；不把一句完整的话硬切成两段，不为断而断（短段连排的碎节奏与长段
一样伤阅读）。

**标题与正文配合：** 标题抛问题或冲突，不复述正文结论、不重复正文信息；
主标一行内说清。小标题是路标不是金句：不复述下文结论，不作对仗。数字预告
式标题（"X 个方法"）只用于干货清单型。

**视觉元素边界：** 沿用结构装饰判断标准——每个视觉元素（加粗、引用块、配
图位、分隔线）须答得出"删掉它论证是否受损"，答不上来即装饰。加粗只用于
段内承重词，每段至多一处；配图放在论证节点（举证、换气、场景切换）上，不
放装饰位；分隔线用于节与节之间，不用于段与段之间。

**交付：** 排版调整单独出 diff（只含分段与视觉元素变化）；排版过程确需改
字的（如拆段后补连接词），该处按内容 diff 单独标注。

## 样本库

安装者提供有权使用的作者原文。把样本和本次写作的事实素材分别标明，以免把样本中的情节写进新稿。

| 样本 | 用途 |
| --- | --- |
| 未改写的闪念、日记和手写笔记 | 校准真声。文体匹配优先，主题相近其次 |
| 未经润色的本人语音转录 | 校准口语语气、回指和自我修正 |
| 已发表文章 | 只校准发表形态与排版节奏 |
| 人机对话 | 作者本人写的部分可作真声样本，AI 回复只作待核对素材 |
| AI 辅助稿与改稿对照 | 只用于识别偏差 |

缺少真声原文时，请用户提供两到三篇同文体样本。用户手头只有当前素材时，先整理素材与骨架，标明文风校准待补。需要确认骨架时，提供具体的段落取舍，并附可以独立验收的约 300 字试写，确认后展开。

实际评审可用 [骨架与差异对照表](references/review.md)。
