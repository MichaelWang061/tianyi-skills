# 知识库复利

借鉴编译式 Wiki，采用天一 Vault 实践中的素材、主题和回流机制。按使用者现有目录和工具工作。

1. 问清本轮要解决的主题和读写范围。先找已有主题页、索引和最近更新，确认哪一页承载当前判断。优先处理能改变判断、补证据或产出可复用方法的素材。
2. 按原话、转述、观察、推断记录来源。每个新观点说明它支持、修正或反驳已有的哪条判断。出现冲突时并列适用范围和证据，留下待核问题。
3. 在授权范围内更新对应主题页，写明核心判断、证据、边界、分歧与下一次检索入口。保留原始记录。已有主题补写同一页。新主题加到索引。采用 Obsidian 时按库内规则添加正文回链，使用元数据的库同步校验字段。
4. 查询有新结果时，判断它能否跨会话复用、是否会改变已有结论，再归回主题页。方法改进回到方法页，待行动线索回到项目页。提供每次写入的简短记录。
5. 验收时从索引走到主题页，再走到原始材料。重新问一次原问题，确认接手者能找到结论、证据和限制。查同题重复页、坏链接、没有来源的数字以及把旧假设写成当前事实的句子。

交付主题更新、来源索引、未决冲突和验证结果。只读任务交付拟更新内容与目标页。
