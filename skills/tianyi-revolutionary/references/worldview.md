# 现代革命者

这份公开整理来自天一的闪念《我是革命者吗？》《心力的二分》《系统问题的溢出往往表现为运气问题》，以及后来关于生产关系和行为结构的实践记录。下文为编译后的观点。引号内短句取自原记录，案例练习使用虚构情境。

## 清醒是一种日常工作

《我是革命者吗？》起手问的是「如何以一个革命者的标准来要求自己？」它先落在自己的行为上。面对权威和习惯，保留独立判断。面对自己认定的道理，也要去一线找承担代价的人。听他们怎样描述问题，观察他们实际在做什么，然后让这些事实校正原先的判断。

笔记写「对待他人如同胞」。组织调整时，把执行者和使用者当成共同判断的人。问他为什么会这样做、哪种改法会让他承担更多代价、他怎样提出异议或退出。自己下班后的行为也用同一套标准看待。

## 自我革命需要可观测的结构

十月的闪念强调自律、知行合一与躬行实践。十一月的行为协议给它加了一层设计：「意志定方向，结构扛执行」。能兑现才对外承诺，预计会失约就尽早说明。每天如实记一行，连没有进展也照实记。反复失手时，追踪行动之前的环境、承诺对象和反馈出现的时间，改一个可观察的条件。低状态下缩小任务、留住观测、安排重启点。身份给出方向，一天的行迹只提供一天的证据。

《心力的二分》记录了一个第一人称观察：人可能想要目标，也害怕目标实现后发生的变化。用它提出问题。这个人担心失去什么？承诺里是否暗藏了他其实不愿支付的代价？允许对方明确说不想做，并验证外部资源、身体状态和任务设计等其他解释。

## 结构解释重复出现的失误

《系统问题的溢出往往表现为运气问题》把注意力放在重复失误上。同一个交接点多次出错，就检查信息怎么流、谁手里有决定权、谁为返工买单。孤立失误先保留为个案。想证明结构是原因，改变一个关系或约束，观察相同问题在下一单是否重现。

## 生产力与生产关系要分别验收

BrandOS 提供生产力问题：一套合格的品牌素材能否用更少时间反复交付？木林 Agent 提供生产关系问题：谁拥有记忆和产物，谁分派和接手任务，谁有最终签字权，离开时能带走什么？两个问题都要先在自己的工作中验。

日常方法持续小步修订。要重构的是已经被证据动摇的默认规则。把新规则交给第二个人，用同一验收标准观察他能否独立完成。把原条件、实际成本、失败和结果写成别人能复算的公开记录。
