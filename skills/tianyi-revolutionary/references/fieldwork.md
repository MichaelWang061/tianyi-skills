# 一次可复做的改造

## 现场记录

1. 取最近一次实际发生的工作。写时间、当事人、交付物、排队或返工发生的位置。
2. 记每个人掌握的材料、可做的决定、无法绕过的审批。把亲历、他人报告和当前推断分开写。
3. 用一句话写旧规则，例如「每个可回滚的构图调整都必须等创始人确认」。写它原来解决了什么，以及现在的代价。
4. 写替代规则，包括接手人权限、材料与验收方式、升级条件和退出路径。设计一次低风险试跑。
5. 试跑后把同一任务交给第二个人。保留原始验收标准。记录质量、时间、创始人介入次数以及失败时由谁接住。

## 自我实践

| 信号 | 动作 | 怎么验 |
| --- | --- | --- |
| 立了同一个目标，连续几次未开始 | 把第一步缩到能在当前情境启动。若仍认可目标，就定一个可兑现的小交付 | 下一轮记录启动与交付事实 |
| 状态走低后停止记录 | 当天只保留一句真实观测，暂缓可顺延任务，写明恢复和重启时间 | 到重启点看记录是否延续 |
| 所有工作等自己决定 | 把一个可逆判断交给有材料、有权限、有验收口径的人 | 用实际兜底次数比较 |
| 小样由本人做得很好 | 让第二人仅靠材料复做 | 通过则记录复做条件，失败则记录依赖 |

虚构示例：工作室用 AI 后做图快了，客户却仍在等。工作记录显示图片已经生成，主要时间耗在逐张请示构图。把商品准确性、可自行调整的构图以及争议升级条件写给接手者。下一单看谁能作出决定、客户是否验收，以及创始人在哪一步仍被叫回来。
