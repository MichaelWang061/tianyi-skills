# 方法地图

## 已有可用入口

- [革命者视角](../skills/tianyi-revolutionary/SKILL.md)从思想笔记、行为协议和生产关系分析中提炼个人判断及实践准则。
- [voice-anchor](../skills/voice-anchor/SKILL.md)来自反复改稿、病例复盘和内容创作引擎交接。
- [公开工作记录](../skills/tianyi-build-in-public/SKILL.md)把具体交付、失败与证据变成别人能复用的内容。
- [知识库复利](../skills/tianyi-knowledge-compounding/SKILL.md)把收件、编译、回链和查询回流接成一套更新流程。
- [可重启的 Agent 循环](../skills/tianyi-agent-loop/SKILL.md)把工程实践里的基线、验证、停止和交接做成工作单。
- [超级组织](../skills/tianyi-super-organization/SKILL.md)从木林 Agent 和人机协作治理规范提炼分工与权责。
- [品牌内容系统](../skills/tianyi-brand-content/SKILL.md)从 BrandOS 的产品和交付设计提炼模板与验收。
- [流量先行选品](../skills/tianyi-commerce/SKILL.md)来自 AI-native 电商品牌实验。商业有效性由实际测试决定。

## 待形成 Skill 的主题

| 主题 | 已有材料 | 还需要什么 |
| --- | --- | --- |
| 自然过程与系统设计 | 风的动力、雪球的初始条件与正反馈、结构性故障 | 同一套问法在产品、组织和内容中分别做完一轮案例，说明反馈何时失效 |
| AI UGC 广告生产 | 广告公式、视觉生产工作流和行业交付场景 | 可分享的输入素材、跨场景样片及客观验收表 |
| 品牌出海与获客 | 品牌出海方法论、渠道运营和项目交付经验 | 一组可公开的渠道成本、线索质量和后续转化记录 |
| 个人正循环 | 能量、输出、真实反馈与恢复机制 | 能公开且能让其他人独立复做的观察记录 |
| 选题、开头和标题 | 已有分主题方法论及创作引擎工作流 | 一组同题多版本的实际比较，确认每个 Skill 的输入、产出与边界 |
